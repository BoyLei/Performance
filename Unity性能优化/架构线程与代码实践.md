# 架构线程与代码实践

## Callback与UniTask

来源：[[历史问题索引#Unity异步方案对比]]。复杂业务顺序可使用 UniTask 表达，持续广播与底层兼容接口仍可保留事件或 Callback。适配层必须明确取消、异常与完成次数，不能认为换语法就获得性能收益。

## 无状态与线程安全

来源：[[历史问题索引#分支 · 讲解 Unity 内存原理]]。无实例字段不等于线程安全；静态缓存、对象池、共享缓冲区、原生解析库和输入对象都可能共享可变状态。并行解析应各自拥有输出与临时缓冲，查清依赖库契约，再把表现层操作交回 Unity 主线程。

## Timer与GC纠错

最小堆解决找最近触发时间的复杂度，不使主线程免受 GC 停顿。System.Threading.Timer 通常在线程池回调，也不能保证实时性，更不能直接调用普通 Unity 对象 API。暂停后补触发需要上限，避免一次执行堆积回调。

值类型的存储位置取决于容器与逃逸、装箱等因素，不能概括为 struct 一定在栈。foreach 是否分配取决于枚举器和接口路径，RemoveAt 主要是搬移成本，不应一概归为 GC 分配。

## MVC MVP MVVM与依赖

MVC 组织模型、视图与控制器；MVP 用 Presenter 驱动视图接口；MVVM 用 ViewModel 和绑定同步状态。依赖倒置是高层与低层依赖抽象的设计原则，依赖注入是提供依赖的方式之一。框架选择不能替代事件解绑与生命周期约束。

PropertyChangedEventArgs 可按属性名缓存不可变实例，避免每次通知新建；不同属性不能总用同一个错误名称。去掉重复通知往往比只缓存参数更有价值。

## HFSM

活跃层级可以用叶状态加父链、显式路径或 ActiveChild 表达；ActiveChild 字段不是 HFSM 的必要条件。切换时从旧分支退出到公共祖先，再进入新分支。父级是否持续更新、事件先给子还是先给父、重入和中途切换规则都要明确。原始示例已沿父链 Enter/Exit 并可向父级派发事件，旧自我纠错声称它从不调用父级 Enter/Exit 并不属实；示例真正缺少 Tick 策略、重入与完整异常边界，应以状态迁移测试验收。

## 包版本与xLua

### Q060–Q062：ShaderGraph 与包位置

ShaderGraph 是用节点描述并生成 Shader 的编辑工具，不是替换整个渲染管线；节点、Target 与生成 Pass 取决于 ShaderGraph/SRP 包版本。Unity 2022 截图中出现的 12.1.9/12.1.15 不能据文本直接推断正确安装组合，需核查编辑器版本、`Packages/manifest.json`、`packages-lock.json` 与包依赖。

注册表包通常解析到 `Library/PackageCache`，它是生成缓存，不应作为持久修改源；Embedded 包在 `Packages/<包名>`，Local 包按 manifest 的 `file:` 路径解析。Package Manager 的显示路径以实际来源为准。[本地包安装](https://docs.unity3d.com/2022.3/Documentation/Manual/upm-ui-local.html)。缺失截图仍无法复验。

Shader Graph、SRP Core、URP 的依赖必须按包声明及 Editor 版本配套，不能直接将本地旧 Core 与较新 Shader Graph 强配。历史截图未包含像素，无法重现具体报错。

归档历史问过 Lua 改成 `.lua.txt`：常见用途是让 Unity 按 TextAsset 导入，再由 xLua 自定义 loader 读取；后缀不改变 Lua 语义，也不意味着加密。Addressables/Bundle 地址约定应与加载器一致。

## HFSM、绑定与包管理补充

Q120 的 Run→Jump 应退出 Run、Ground，再进入 Air、Jump；Run→Idle 不退出 Ground。并行的移动与攻击通常需要正交状态区或多个协调 FSM，不能只把它们变成同一互斥分支的兄弟状态就消除组合问题。行为树、HFSM、GOAP 不是按状态数量固定升级的优劣阶梯。Q122 的项目入口可查看 [Stateless](https://github.com/dotnet-state-machine/stateless)、[UnityHFSM](https://github.com/Inspiaaa/UnityHFSM)、[HFSM2](https://github.com/andrew-gresyk/HFSM2)，本轮未统计星数或验证 Unity/AOT 兼容性。

INotifyPropertyChanged 不提供 Unity UGUI 自动绑定或线程切换；通知在线程发起方同步派发，应在主线程更新 View，并在解绑时释放订阅。缓存每属性 EventArgs 可以减少通知参数分配；若用空名称代表全部属性刷新，可能放大刷新成本。CommunityToolkit 等框架是否缓存参数取决于源码生成与具体版本，不能一概声称没有缓存。MVC/MVP 的具体变体不同，历史 Login 示例只是组织方式演示，不应成为三种模式的唯一定义。

Q059–Q063 的包目录名不证明实际版本，检查 package.json、manifest、lock 和本地源码差异；先保留修改并对齐依赖，再重新解析。不要把删除 packages-lock.json、Library 全缓存作为日常第一步，那会丢失依赖解析依据并可能改变传递版本。缺失截图无法证明 Cinemachine 报错已重现。

Q136 的 xLua `.lua.txt` 是 TextAsset 导入与 loader 路径约定；自定义 LuaEnv.AddLoader 可直接提供字节。扩展名、加密与字节码兼容性是三回事，Resources 示例的路径规则不能直接当作所有 Bundle/Addressables loader 的规则。
