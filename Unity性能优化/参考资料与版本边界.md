# 参考资料与版本边界

## 适用范围

未取得实际项目的 Editor、URP、Addressables、UniTask 和平台版本。原理文档采用通用描述；场景示例参考历史中的 Unity 2022.3 URP，不表示用户项目版本已确认。API 与插件行为应以项目锁定版本核对。历史回答经过归纳，不能作为已实测结论。

## 官方参考

- [Unity 2022.3 SRP Batcher](https://docs.unity3d.com/2022.3/Documentation/Manual/SRPBatcher.html)：核对常规 Renderer 兼容条件和材质缓冲区。
- [Addressables 1.21 内存管理](https://docs.unity.cn/Packages/com.unity.addressables%401.21/manual/MemoryManagement)：引用计数与依赖释放。
- [Addressables 1.20 加载](https://docs.unity.cn/Packages/com.unity.addressables%401.20/manual/LoadingAddressableAssets.html)：加载句柄与异步路径。
- [UniTask 官方仓库](https://github.com/Cysharp/UniTask)：PlayerLoop、取消、线程切换与分配边界。
- [Mind map editor 官方仓库](https://github.com/vulture039/obsidian-mindmap-editor)：标准大纲、复选框与双向编辑。
- [Tasks 查询过滤器](https://publish.obsidian.md/tasks/Queries/Filters)：not done、path、tag 等查询。

以上为前次本地整理记录的参考入口；本轮实际重新读取的版本材料列在下面，不将旧访问记录当成本轮检查证据。

## 插件兼容性

本地检测到 Mind map editor 1.9.0（最低 Obsidian 1.12.3）、Tasks 8.7.0（最低 Obsidian 1.13.1）。安装文件存在不能证明插件已启用，也未取得 Obsidian 应用版本。未修改 `.obsidian`。

Mind map editor 本地解析代码可识别标题、嵌套列表和 `[ ]` / `[x]`。本库仅使用这些标准大纲元素；任务优先级用普通标签，避免不同插件优先级符号互相改写。复杂表格、Mermaid 和查询块放在独立笔记中，不要求脑图解析。

未进行应用内脑图编辑往返、Mermaid 渲染或 Tasks 查询执行测试。建议首次打开 [[学习任务脑图]] 后在一个任务上试勾选并撤销，确认 Markdown 同步。若插件不兼容，源 Markdown、原生链接和复选框仍可使用。

## 本轮技术核查依据

核查日期：2026-11-26。以下是文档/源码静态核对，不等同 Unity 或 Obsidian 运行测试；实际项目版本尚未提供。

- [PlayerLoopSystem 2022.3](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/LowLevel.PlayerLoopSystem.html)：updateDelegate、updateFunction、loopConditionFunction 的类型与用途。
- [UnloadUnusedAssets 2022.3](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Resources.UnloadUnusedAssets.html)：遍历组件/静态变量，不遍历脚本执行栈。
- [allowSceneActivation 2022.3](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AsyncOperation-allowSceneActivation.html)：0.9 门控、isDone 与队列停滞。
- [Unity 增量 GC 2022.3](https://docs.unity3d.com/2022.3/Documentation/Manual/performance-incremental-garbage-collection.html)：Boehm 与 non-compacting 边界，不能套用桌面 .NET 分代压缩解释。
- [ParticleSystem prewarm 2022.3](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/ParticleSystem.MainModule-prewarm.html)、[Simulate 2022.3](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/ParticleSystem.Simulate.html)：循环预热、模拟后暂停与参数语义。
- [InvokeRepeating 2022.3](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.InvokeRepeating.html)：缩放时间语义；不能用这份文档证明所有禁用场景的实际回调行为。
- [uGUI 固定提交 2f222353](https://github.com/Unity-Technologies/uGUI/tree/2f2223531d1e8177bcdf83c81f6c3aba1f9f14ab/com.unity.ugui/Runtime/UGUI)：EventSystem、StandaloneInputModule、Graphic、CanvasUpdateRegistry、LayoutRebuilder；新主分支作为明确版本样本，不冒称就是项目 2022.3 包。
- [Addressables 1.21.21 官方包](https://packages.unity.com/com.unity.addressables/-/com.unity.addressables-1.21.21.tgz)：读取 Runtime/AddressablesImpl.cs、ResourceManager/ResourceManager.cs、AsyncOperations/ProviderOperation.cs、ResourceProviders/AssetBundleProvider.cs；对照定位、缓存、依赖、Provider 与 true 卸载分支。无需将包源码复制进本库。
- 本仓库的 `.obsidian/plugins/*/manifest.json` 只读核对：Mind map editor 1.9.0/minAppVersion 1.12.3，Tasks 8.7.0/minAppVersion 1.13.1；未改配置、未加载插件。最低版本来自 manifest，不代表已确认宿主版本。

本轮额外在隔离临时目录使用 Mermaid 11.12.2 解析器检验文档图语法；该版本不代表 Obsidian 内置 Mermaid 版本。Tasks 查询仅做静态约束检查与源任务匹配，脑图层级仅做 Markdown 结构检查。实际渲染、编辑往返和查询执行仍须本地应用验收。
