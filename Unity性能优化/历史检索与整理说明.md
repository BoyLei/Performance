# 历史检索与整理说明

## 前次本地检索（交接记录）

2026-11-26 检查目标路径可读写。活动 ChatGPT 历史列表返回 41 个会话，归档列表两页共 73 个；按标题筛选并读取 35 个活动相关会话及 5 个归档候选。归档候选仅 xLua 内容属于本库技术范围，其余为工具配置或泛聊，未导入无关配置。

实际纳入 36 个会话的可返回内容，活动部分 136 个返回轮次，连同归档 xLua 合计保留 136 条用户原问或后续短问。见 [[历史问题索引]]。对话标题可能与最后返回的问题不一致，例如“讲解 Unity 内存原理”的可见部分实际集中于 GPU Mask；因此按内容归档。

每次 read_thread 请求 turnLimit=10，接口实际大多只返回 1～5 轮，所有返回页均为 hasMore=false、nextCursor=null。这表示无可用的更早游标，不代表原会话全部历史已获取。分支的继承消息、早期 GPU 或内存讨论可能缺失。没有把标题和上一轮举例当作完整原问证据。

## 缺口与处理

- 原会话中有图片的地方，返回文字仅注明附件存在，未取得图片像素；不推断截图中的错误与设置。
- 当前接口未提供更早页面时，未声称已经收齐所有 Unity 历史。以后有导出记录可按原会话 ID 与轮次补录。
- 未检出仅指本次可见内容。TODO 中如果已有部分历史解释，会标“已提及待实战”，不写成确定从未问过。
- 历史回答中的团队内部经验、行业归属、产品路线或未经测量的倍数不作为事实继承。

## 去重与纠错规则

主模块保存概念解释，专项保存具体场景；原问只在索引保存。关联使用同名双向链接。重点纠正：SRP Batcher 不等于合并 Draw Call；LOD 切换不必然重传 Buffer；async 不等于后台线程；Timer 不免疫 GC；Destroy 节点不等于资源立刻释放；RT 存在不等于自动绘制。

模块状态 mixed 表示整理与历史混合，不代表模块每个知识点都有原始提问。任务标签 discussed 表示可见问题或回答涉及该主题；review-required 表示原文证据不足以确认具体范围；not-found 表示没有找到明确讨论。
