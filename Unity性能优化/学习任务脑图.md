# 学习任务脑图

每个知识点只在这里保存一项任务。父节点仅作分类，不建立父任务，避免把父子重复计数。勾选表示已按验收要求完成；讨论标签独立，不随勾选改变。

- [[01 GPU与渲染]]
    - [ ] 帧流水线与瓶颈：在真机同一镜头分别降低分辨率、阴影和物体数，记录 GPU 与 Render Thread 时间，判断填充、几何还是提交受限。 #unity-task #priority/P0 #discussion/discussed
    - [ ] SRP Batcher与GPU Instancing：固定同一批石头，分别测普通提交、SRP Batcher、实例化；同时记录 CPU 提交、GPU、批次、顶点数。 #unity-task #priority/P0 #discussion/discussed
    - [ ] CBUFFER与MPB：比较共享材质、独立材质与 MPB 的内存和提交时间，检查 Frame Debugger 原因。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 可见性与LOD：验证跨块大型建筑不会过早消失；对比网格合并前后的可见三角形与批次。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 透明与带宽：在同一画面降低透明覆盖面积与渲染比例，观察 GPU 时间变化。 #unity-task #priority/P0 #discussion/discussed
    - [ ] Shader Pass与Variant：建立实际材质和关键字清单，在构建日志核对保留与剔除数量。 #unity-task #priority/P0 #discussion/discussed
- [[02 CPU与调度]]
    - [ ] PlayerLoop与Update：采样主线程 Timeline，将脚本、动画、物理和渲染准备拆开统计。 #unity-task #priority/P0 #discussion/discussed
    - [ ] FixedUpdate与时间：记录一秒内固定步数量，验证不同帧率下移动与碰撞一致性。 #unity-task #priority/P0 #discussion/discussed
    - [ ] Timer系统：比较 100、1000、10000 个计时器的调度成本与误差，检查取消后不再回调。 #unity-task #priority/P0 #discussion/discussed
    - [ ] Jobs与Burst：识别可独立计算的视野或距离数据，先测串行基线，再评估并行。 #unity-task #priority/P0 #discussion/review-required
- [[03 内存与GC]]
    - [ ] 托管与原生所有权：在空场景、加载后、销毁后、释放后各抓快照，比较引用链和原生对象。 #unity-task #priority/P0 #discussion/discussed
    - [ ] GC分配与卡顿：用 GC.Alloc 调用栈定位热点，复测 P95/P99 帧耗时而非只看平均 FPS。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 对象池与峰值：往返场景十次后检查池、事件监听和资源引用是否回到稳定水平。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 字符串与缓冲区：比较热路径分配，检查日志与 UI 格式化频率。 #unity-task #priority/P0 #discussion/discussed
- [[04 纹理与资源]]
    - [ ] ASTC与纹理内存：对同一纹理比较 ASTC 4×4、6×6、8×8 的细节与真机内存。 #unity-task #priority/P1 #discussion/discussed
    - [ ] 格式回退与平台：在目标设备核对实际 graphicsFormat、尺寸、mipmapCount 与快照。 #unity-task #priority/P1 #discussion/discussed
    - [ ] SpriteAtlas与合图：按共同加载生命周期拆图集，测界面切换时纹理驻留与批次。 #unity-task #priority/P1 #discussion/discussed
    - [ ] Mip与资源预算：为目标机型制定纹理、网格、音频预算和加载峰值阈值。 #unity-task #priority/P1 #discussion/discussed
- [[05 Addressables与AssetBundle]]
    - [ ] 地址与依赖图：查看 Build Layout，记录共享纹理、材质与 Shader 的实际归属。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 引用计数与释放：建立加载、失败、取消、销毁四条路径的资源配对表。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 循环引用与卸载：用构建报告查强连通依赖组，比较拆分前后加载峰值。 #unity-task #priority/P0 #discussion/discussed
    - [ ] Resources与启动：记录启动各阶段时间，移除无用资源后对比包体和启动采样。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 粒度与抖动：沿同一路线往返，记录 Bundle 重载次数和峰值。 #unity-task #priority/P0 #discussion/review-required
- [[06 异步与生命周期]]
    - [ ] 协程与await：把重计算放在 await 前后分别采样，观察卡顿是否仍在主线程。 #unity-task #priority/P0 #discussion/discussed
    - [ ] UniTask机制：比较协程、Task 与 UniTask 的分配、恢复阶段与取消行为。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 取消与过期结果：模拟快速进出区域与重复点击，验证过期回调不创建孤儿对象。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 异步加载仍可卡顿：对比分帧创建与一次性创建的 P99 帧耗时及总加载时间。 #unity-task #priority/P0 #discussion/discussed
    - [ ] 场景激活与取消：测试加载到激活前退出、快速重进和失败重试三条路径。 #unity-task #priority/P0 #discussion/discussed
- [[07 场景流式与地形]]
    - [ ] 编辑场景与运行产物：对比编辑 Scene 与运行 Scene 的引用依赖，确认加载基线降低。 #unity-task #priority/P1 #discussion/discussed
    - [ ] Chunk与Bounds：用跨边界大建筑、负坐标和非零地图原点验证归属与加载。 #unity-task #priority/P1 #discussion/discussed
    - [ ] 加载滞回与状态机：沿边界来回和瞬移测试，记录重复实例、迟到结果与未释放句柄。 #unity-task #priority/P1 #discussion/discussed
    - [ ] Terrain草树与真正流送：256m、Detail 1024、每 Patch 32 时得到 32×32 Patch，每块 8m，仅作尺寸推导与测试起点。 #unity-task #priority/P1 #discussion/discussed
    - [ ] Prefab Override：导出蓝色屋顶、添加子节点和复杂父变换样例，比较编辑与运行结果。 #unity-task #priority/P1 #discussion/discussed
    - [ ] 碰撞与服务器导航：验证玩家高速移动时碰撞不缺失，并与服务器对同一条路线核对。 #unity-task #priority/P1 #discussion/discussed
- [[08 UGUI与交互]]
    - [ ] 重建链路：对同一 UI 分别修改颜色、文本与尺寸，观察 Canvas 和布局采样。 #unity-task #priority/P1 #discussion/discussed
    - [ ] Canvas拆分：比较整页重建与动态区域独立 Canvas 的 CPU 和 Draw Call。 #unity-task #priority/P1 #discussion/discussed
    - [ ] 点击与射线：验证遮挡、父级处理、拖拽后点击以及多 Canvas 排序。 #unity-task #priority/P1 #discussion/discussed
    - [ ] CanvasGroup与隐藏：比较 SetActive、Canvas.enabled 与 CanvasGroup 的隐藏恢复成本。 #unity-task #priority/P1 #discussion/discussed
    - [ ] 架构与列表：对比 1000 行全创建与可见行复用的分配、重建和内存。 #unity-task #priority/P1 #discussion/discussed
- [[09 角色动画与特效]]
    - [ ] 角色成本分解：按 10、50、100 个同屏角色测动画、蒙皮和阴影时间。 #unity-task #priority/P1 #discussion/review-required
    - [ ] 动画LOD与状态机：验证远处降频后的位移、事件、回到近处时姿态恢复。 #unity-task #priority/P1 #discussion/review-required
    - [ ] 粒子对象池：连续复用同一爆炸特效，验证无残留、无漏回收和无提前消失。 #unity-task #priority/P1 #discussion/discussed
    - [ ] 特效预算：大规模战斗中分别降低粒子数与屏幕覆盖，确认真正瓶颈。 #unity-task #priority/P1 #discussion/discussed
- [[10 MMO架构与网络]]
    - [ ] 关注范围与表现：验证进入 AOI、模型加载中离开、再次进入的完整状态转换。 #unity-task #priority/P1 #discussion/review-required
    - [ ] 同步与插值：用延迟、抖动、丢包轨迹验证移动与动画一致性。 #unity-task #priority/P1 #discussion/discussed
    - [ ] TCP消息边界：测试前缀拆开、消息拼接、超长长度和断线残包。 #unity-task #priority/P1 #discussion/discussed
    - [ ] 大规模预算：在城镇和战斗两条固定路线建立可重复基线，记录温度和分辨率。 #unity-task #priority/P1 #discussion/review-required
