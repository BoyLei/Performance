# 优化方向补充与学习路线

以下 24 项是补充学习候选，不能写成“你从未问过”。现存用户原问未明确展开这些具体子问题；其中阴影、抗锯齿、探针、动画、物理、NavMesh、音频、IL2CPP、Jobs、TMP、UI Toolkit、缓存、CI 等基础词已在旧回答或现有笔记出现，应视为深化。API 专项在有限记录中未见明确展开，也不证明完整历史没有讨论。

这是可验证的学习路线，不是 24 条已实现优化。先测瓶颈，P0 处理测量，P1 处理当前热点，P2 再按需求扩展；全部学习任务留在 [[未讨论与待核实路线]]，默认未勾选。与旧任务重合的音频、NativeContainer 合并为这里的细化项，避免重复计数。

版本基线为 Unity 2022.3 / URP14；Collections2.1、Adaptive Performance5.1、TMP3.0、Performance Testing3.0 是参考包版本，不表示项目已安装或兼容。官方链接是阅读入口；取得文档只支持 API 契约，不支持本项目收益。N05/N06 使用 Universal Renderer 入口；N11/N21 原细页请求失败，保留替代入口待继续核实，不据此宣称详细配置已验证。
