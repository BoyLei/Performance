# 07 场景流式与地形

本模块为归纳后的原理与实践建议。历史原问集中在 [[历史问题索引]]；无原文支持的扩展不视为用户问过。

## 编辑场景与运行产物

美术编辑完整地图，构建阶段导出运行 Scene、Chunk、共享原型和服务器导航。运行 Scene 不应继续直接持有完整建筑表现资源，否则仅禁用节点仍可能加载其数据。

**验证与验收：** 对比编辑 Scene 与运行 Scene 的引用依赖，确认加载基线降低。

## Chunk与Bounds

Chunk 决定加载粒度，Mesh Combine 决定绘制组织，二者独立。按 floor((position-origin)/size) 分块能处理负坐标；跨块建筑用 Bounds 与稳定 ID 去重，不能只看中心点。

**验证与验收：** 用跨边界大建筑、负坐标和非零地图原点验证归属与加载。

## 加载滞回与状态机

设置卸载距离大于加载距离减少边界抖动。每块需要 Unloaded、Loading、Loaded、Unloading 等状态并合并重复请求；generation 防止旧请求覆盖新意图。高速移动还需预取与队列优先级。

**验证与验收：** 沿边界来回和瞬移测试，记录重复实例、迟到结果与未释放句柄。

## Terrain草树与真正流送

Detail Patch 是地形内部绘制组织，不等于独立资源文件；距离隐藏也不等于卸载。地形可常驻，草树数据独立导出；导出后必须避免运行时原生和自研系统重复绘制。

**验证与验收：** 256m、Detail 1024、每 Patch 32 时得到 32×32 Patch，每块 8m，仅作尺寸推导与测试起点。

## Prefab Override

只导出 PrefabId、Transform、Bounds 会丢失其他实例修改。整体变换单独记录；颜色等白名单参数可参数化；结构差异使用 Variant 或独立 Prefab。Variant 不能任意删除继承节点。去重 Hash 需要稳定处理对象引用与结构差异。

**验证与验收：** 导出蓝色屋顶、添加子节点和复杂父变换样例，比较编辑与运行结果。

## 碰撞与服务器导航

客户端表现流送和碰撞、服务器导航有不同生命周期。必要的简化碰撞可先常驻，避免表现未到位就穿墙。导航三角化输出不是服务器原生寻路格式的完整替代，需确认区域、连接、tile 和坐标约定。

**验证与验收：** 验证玩家高速移动时碰撞不缺失，并与服务器对同一条路线核对。
