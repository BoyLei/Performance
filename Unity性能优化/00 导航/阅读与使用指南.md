# 阅读与使用指南

> [!tip] 两种展开方式
> **Canvas** 双击即可打开，无须第三方脑图插件；Markdown 脑图通过 Mind map editor 命令展开。

## 从大到小阅读

[[00 知识库首页|首页]] → [[学习总览.canvas|总览图谱]] → 四个主题域 → 模块分图 → 模块标题锚点 → 原文、核验和学习任务。先单击选中卡片，再单击其中的链接打开下一层；若处于文本编辑状态，先按 Escape 退出。文本卡片不会自动展开子脑图，请用“继续展开”链接打开分图。

总览只展示模块，知识点在各模块分图继续展开；[[知识体系脑图]] 保留所有技术小节的完整嵌套目录。[[模块依赖与关联]] 单独解释跨模块关系，包含线不代表依赖线。

## 插件命令与任务


安装插件后，Markdown 仍会先以普通笔记显示；Mind map editor 需要单独打开脑图视图。以下对应仓库所带 Mind map editor 1.9.0 和 Tasks 8.7.0，插件必须在“设置 → 第三方插件”中启用。仓库只包含这两个插件，用户本地其他插件请以实际名称为准。

1. 打开 [[知识体系脑图]]，用于浏览主题；或打开 [[学习任务脑图]]，用于管理学习任务。
2. 按 `Ctrl+P`（macOS 为 `⌘P`）打开命令面板，搜索 `Mind map`。
3. 执行 **Mind map editor: Open mind map for the active file**。脑图会在独立视图中打开；左侧工具栏的 **Open mind map** 图标也可使用。
4. 点脑图工具栏 **Fit mind map to viewport** 适配窗口，再用 **Zoom in** 放大。全图文字较小是缩放结果，可折叠分支并平移/滚动查看。
5. 如希望以后打开笔记时自动显示脑图，在脑图工具栏启用 **Open this map automatically with the note**；这是个人使用选择，本仓库没有替用户开启或改写 `.obsidian`。

命令搜不到时，先检查插件是否已启用、是否仍在受限模式，以及 Obsidian 是否达到插件声明的最低版本（Mind map editor 1.9.0 要求 1.12.3，Tasks 8.7.0 要求 1.13.1）。如果安装的是其他同名/类似脑图插件，其命令和用法可能不同。

Tasks 不负责脑图。打开 [[任务总览]] 并切换到阅读视图（`Ctrl+E` / `⌘E`）即可看查询结果；无自定义过滤器时，本库初始四组结果应为 93 / 32 / 0 / 34。仅看到 Tasks 代码块时，检查插件启用状态、阅读视图和全局过滤器。勾选代表自己完成学习，查询中的勾选会写回源任务；讨论标签不会自动表示学习完成。


## 目录与兼容

学习正文、专项、任务、历史来源、核验记录分目录收纳。笔记名称与原标题保留，以唯一笔记名及标题锚点跳转。外部旧完整路径或旧窗口路径可能需要从首页重新打开；本次不改写 `.obsidian`。Canvas 不复制可勾选任务，完成状态仍只来自两份源清单。

## 状态与版本

`discussion_status` 表示资料依据：`mixed` 为历史讨论与补充混合，`supplemental` 为整理补充，`not-found` 为可访问原文未检出。任务的 `discussed`、`review-required`、`not-found` 标签描述讨论状态，不表示学习已完成。`learning_status: pending` 是默认学习状态；文件属性不会由 Tasks 自动更新。没有创建到期日期或自动提醒。

示例以 Unity 2022.3 / URP 为背景，具体项目版本仍待确认。首页压缩了显示属性以突出导航，各技术笔记的完整属性和原版本条件未改动。阅读视图的 Properties 属性区可手动折叠，窗口状态由用户自己选择。
