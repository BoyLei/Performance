# 参考资料与版本边界

## 适用范围

未取得实际项目的 Editor、URP、Addressables、UniTask 和平台版本。原理文档采用通用描述；场景示例参考历史中的 Unity 2022.3 URP，不表示用户项目版本已确认。API 与插件行为应以项目锁定版本核对。历史回答经过归纳，不能作为已实测结论。

## 官方参考

- [Unity 2022.3 SRP Batcher](https://docs.unity3d.com/2022.3/Documentation/Manual/SRPBatcher.html)：核对常规 Renderer 兼容条件和材质缓冲区。
- [Addressables 1.21 内存管理](https://docs.unity.cn/Packages/com.unity.addressables%401.21/manual/MemoryManagement)：引用计数与依赖释放。
- [Addressables 1.20 加载](https://docs.unity.cn/Packages/com.unity.addressables%401.20/manual/LoadingAddressableAssets.html)：加载句柄与异步路径。
- [UniTask 官方仓库](https://github.com/Cysharp/UniTask)：PlayerLoop、取消、线程切换与分配边界。
- [Mind map editor 官方仓库](https://github.com/vulture039/obsidian-mindmap-editor)：标准大纲、复选框与双向编辑。
- [Tasks 查询过滤器](https://publish.obsidian.md/tasks/Queries/Filters)：not done、path、tag 等查询。

以上为本次实际访问的参考入口；其余模块为基础原理归纳与待验收实践，不声称每条均经特定版本源码验证。

## 插件兼容性

本地检测到 Mind map editor 1.9.0（最低 Obsidian 1.12.3）、Tasks 8.7.0（最低 Obsidian 1.13.1）。安装文件存在不能证明插件已启用，也未取得 Obsidian 应用版本。未修改 `.obsidian`。

Mind map editor 本地解析代码可识别标题、嵌套列表和 `[ ]` / `[x]`。本库仅使用这些标准大纲元素；任务优先级用普通标签，避免不同插件优先级符号互相改写。复杂表格、Mermaid 和查询块放在独立笔记中，不要求脑图解析。

未进行应用内脑图编辑往返、Mermaid 渲染或 Tasks 查询执行测试。建议首次打开 [[学习任务脑图]] 后在一个任务上试勾选并撤销，确认 Markdown 同步。若插件不兼容，源 Markdown、原生链接和复选框仍可使用。
