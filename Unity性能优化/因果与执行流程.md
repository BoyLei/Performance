# 因果与执行流程

## 诊断闭环

```mermaid
flowchart TD
  A[固定真机与场景基线] --> B[CPU GPU 内存与加载采样]
  B --> C{关键瓶颈}
  C --> D[CPU 调度与提交]
  C --> E[GPU 几何 填充 带宽]
  C --> F[资源驻留与加载峰值]
  D --> G[一次只改一个变量]
  E --> G
  F --> G
  G --> H[同路线复测 P95 P99 与画质]
  H --> I{满足预算}
  I -->|否| B
  I -->|是| J[保存基线与回归样例]
```

## 场景流送生命周期

```mermaid
flowchart TD
  A[玩家位置与移动方向] --> B[空间索引与 Bounds 查询]
  B --> C[加载阈值 卸载阈值与优先队列]
  C --> D[限并发请求资源并持有句柄]
  D --> E{加载成功且请求仍有效}
  E -->|否| F[按所有权收尾失败或迟到句柄]
  E -->|是| G[按帧预算实例化并启用表现]
  G --> H[持续管理加载状态与请求代次]
  H --> K[退出保留范围]
  K --> I[InstantiateAsync 用 ReleaseInstance 手动实例用 Destroy 后 Release]
```

## 关键权衡

```mermaid
flowchart LR
  A[合并网格] --> B[减少部分提交]
  A --> C[扩大 Bounds]
  C --> D[可能降低剔除精度]
  E[扩大对象池] --> F[降低创建频率]
  E --> G[提高常驻内存]
  H[缩小 Chunk] --> I[降低单次加载粒度]
  H --> J[增加请求与管理开销]
```
